# User Operations Guide

## 1. Passenger Workflows
- Live Tracking: Passengers can select a route to view buses moving in real-time on the map.
- Bus Search: Passengers can input a start and end destination to find matching bus routes and current ETAs.
- Ticketing & Support: Passengers can log lost items or file service complaints.

## 2. Driver Workflows
- Trip Operations: Drivers log in and start a trip, which initiates background GPS broadcasting.
- Route Sequence: Drivers can view the upcoming stops and report manual delays (traffic, accidents).
- End Trip: Drivers explicitly end the trip to release the bus assignment.

## 3. Administrator Workflows
- Fleet Management: Admins have a god-eye view of all buses.
- SOS Monitoring: If a driver triggers an SOS, it flashes on the admin dashboard with exact coordinates.
- Issue Resolution: Admins can review and close out passenger complaints and lost/found tickets.
